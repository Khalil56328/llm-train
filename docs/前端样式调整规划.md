# 前端样式调整规划

## 一、参考样例核心特征

| 维度 | 参考样例风格 |
|------|--------------|
| 主色调 | 红色 `#E60012` / `#E63946` |
| 品牌名 | **训推平台**（左上一抹红色） |
| 顶栏 | 左：红色 logo + "训推平台" ｜ 中：面包屑 ｜ 右：圆形头像 + 用户名（带红色边框） |
| 侧边栏 | 父项：图标 + 文字 + 折叠箭头；子项：往**右**缩进，纯文字；激活态：左侧 3px 红条 + 红字 |
| 页面横幅 | 粉红渐变 + 左侧标题 + 右侧装饰小图标 |
| 搜索条 | 输入框（占位 "请输入XX名称"） + 搜索按钮（图标+文字）+ 重置按钮 + 新建按钮（红色在右） |
| 表格操作列 | "详情 / 更多" 红色文字按钮，间距一致 |
| 表单 | 红色 `*` + label + 输入框；分组标题（红字加粗）；底部右下角 取消/保存 |

## 二、问题点与现状对比

| 位置 | 现状 | 参考样例 | 差异 |
|------|------|----------|------|
| 品牌名 | "训推平台" | "训推平台" | ❌ 不一致 |
| 侧边栏 | 子项图标可选 | 子项纯文字 | ✅ 默认符合 |
| 顶栏 logo | 蓝/红渐变方块 | 红色纯色 + 红字 | ❌ 不一致 |
| 页面横幅 | 渐变带左侧红色 bar | 渐变 + 右侧小图标 | ❌ 缺装饰图标 |
| 搜索条 | 输入框带搜索图标，右侧按钮 | 输入框不带图标，按钮单独 | ❌ 模式不同 |
| 表单按钮 | 行内 flex | 整段卡片 + 分组标题 | ❌ 结构不同 |
| 表格操作列 | link 按钮 + 更多下拉 | 同样 | ✅ 符合 |

## 三、改动范围（按优先级）

### 🔴 P0 - 必须改（影响全局观感）

| 文件 | 改动内容 |
|------|----------|
| `assets/styles/variables.scss` | 微调主色、字体、间距 |
| `components/layout/AppSidebar.vue` | 品牌改"训推平台"，图标样式，激活态红条 |
| `components/layout/AppHeader.vue` | 头部 logo + 用户头像样式 |
| `components/layout/AppLayout.vue` | 整体间距 |

### 🟡 P1 - 应当改（影响关键页面）

| 文件 | 改动内容 |
|------|----------|
| `components/common/PageHeaderCard.vue` | 横幅右侧加装饰图标 |
| `components/common/SearchFilter.vue` | 输入框不加图标，按钮组模式 |
| `components/common/DataTable.vue` | 操作列对齐 + 字号微调 |

### 🟢 P2 - 局部优化（按需改）

| 文件 | 改动内容 |
|------|----------|
| `components/common/SectionForm.vue` | 分组卡片样式（表单页） |
| `views/**` 各列表页 | 应用统一搜索条/表格 |
| `views/training/FineTuneCreate.vue` | 步骤卡片对齐 |

## 四、执行策略

由于改动涉及 30+ 文件，建议**先做 P0+P1 的样式基础**（影响整体观感），让你快速看到效果后再决定 P2 优化。

预计修改文件：
- 4 个 P0 文件
- 3 个 P1 文件
- 共 7 个文件改动即可覆盖全站观感

## 五、可立即开工的执行项

1. **变量文件** — 微调色值、字号、间距常量
2. **侧边栏** — 品牌名、激活态、图标配色
3. **顶栏** — logo 样式、用户头像
4. **页面横幅组件** — 加装饰图标
5. **搜索过滤组件** — 调整按钮结构
6. **数据表格组件** — 操作列对齐

完成后你会看到：
- 全站色调更统一（红色基调更明显）
- 品牌识别一致（"训推平台"）
- 搜索条模式对齐样例
- 横幅有装饰图标更美观
- 表格操作列更整齐
